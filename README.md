# CampusOS

CampusOS is a modular campus management platform.

## Version

V1.0

## Architecture

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: PostgreSQL
- API: REST
- Authentication: JWT

## Project Structure

- `frontend/` — CampusOS web application
- `backend/` — REST API and server-side logic
- `docs/` — Project documentation
